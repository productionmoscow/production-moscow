# Автоматический деплой ProductionMoscow.ru

После настройки push в `main` запускает GitHub Actions на уже подключённом
self-hosted Mac mini. Workflow проверяет lint, production-сборку и rendered
HTML-тесты, затем передаёт этот репозиторий существующему локальному скрипту
деплоя Mac mini. SSH-ключи в этот репозиторий не копируются.

Сайт работает отдельно от CLEVENT и других проектов:

- идентификатор деплоя: `productionmoscow/production-moscow`;
- workflow запускается на runner с метками `self-hosted`, `mac-mini`, `arm64`;
- публикация выполняется существующим локальным скриптом Mac mini.

## Одноразовая настройка сервера

Контур Mac mini и его reverse proxy уже используются другими сайтами. Для
Production Moscow локальный скрипт получает отдельный идентификатор
`productionmoscow/production-moscow`, поэтому не должен менять каталоги или
сервисы других сайтов.

Если скрипт ещё не знает этот идентификатор, его регистрация должна быть
сделана отдельно на Mac mini владельцем серверного контура. В этот репозиторий
не добавляются ключи, пароли, конфиги Caddy или настройки других сайтов.

## Secrets репозитория GitHub

Для этого варианта отдельные SSH secrets в репозитории не нужны: workflow
использует self-hosted runner Mac mini и локальный деплойный контур.
