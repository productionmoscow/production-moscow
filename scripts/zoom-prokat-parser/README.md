# Zoom Prokat parser

Внутренний источник актуальных цен аренды оборудования для Production Moscow.
Парсер получает каталог `https://zoom-prokat.ru/`, сохраняет Excel для команды и
разбивает каталог на Markdown-чанки для RAG ассистента.

В Excel сохраняется цена за сутки в листе `equipment_prices`. В RAG-файлах
сохраняется та же цена и дата обновления; наличие, комплектность и условия
конкретной аренды требуют подтверждения у проката.

Запуск:

```bash
npm ci
npm test
npm run scrape
```

Обновление RAG и Excel выполняется общей еженедельной задачей знаний Production
Moscow на Mac mini.
